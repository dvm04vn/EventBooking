# 🎟️ EventTicket Frontend

Giao diện web hiện đại cho hệ thống **quản lý sự kiện & đặt vé trực tuyến**.

---

## 🧩 Giới thiệu

**EventTicket Frontend** là ứng dụng web được xây dựng bằng **ReactJS + Vite**, giúp người dùng:

- Tìm kiếm & xem **thông tin sự kiện**
- **Đặt vé** và **thanh toán trực tuyến**
- Theo dõi **lịch sử đặt vé**
- **Đăng nhập / đăng ký** tài khoản
- Quản lý **thông tin cá nhân**

Ứng dụng kết nối trực tiếp với **EventTicket Backend** để cung cấp trải nghiệm:

- Nhanh chóng ⚡
- Mượt mà 🧊
- Bảo mật 🔐

---

## 🚀 Công nghệ sử dụng

### 🧱 Frontend

- **ReactJS (Vite)**
- **SCSS**
- **Axios**
- **React Router DOM**
- **Context API / Redux** (tùy chỉnh)
- **ZaloPay / MoMo / PayPal SDK**
- **JWT Storage**
- **Cloudinary loader**
